## Executive Summary

This document describes the complete refactoring of `main_with_no_framework.py` (1,548 lines) into a modular, production-ready package structure. The refactoring maintains 100% functional compatibility while dramatically improving:

- **Maintainability**: 20+ focused modules vs. 1 monolith
- **Testability**: Dependency injection enables unit testing
- **Type Safety**: Pydantic models validate data
- **Configuration**: Environment-based settings
- **Error Handling**: Custom exception hierarchy
- **Production Readiness**: Proper logging and architecture

### Key Metrics

| Metric | Before | After |
|--------|--------|-------|
| **Files** | 1 | 20+ |
| **Lines per file** | 1,548 | 150-300 |
| **Configuration** | Hardcoded constants | Pydantic Settings from env |
| **Error handling** | Generic exceptions | 6 custom exception types |
| **Logging** | Print statements | Structured logging |
| **Testability** | Difficult | Easy with mocks |
| **Type safety** | Partial | Full Pydantic validation |

## Key Improvements

### 1. Configuration Management

**Before:**
```python
# Constants at top of file
SUBMIT_PREDICTION = True
NUM_RUNS_PER_QUESTION = 5
TOURNAMENT_ID = "fall-aib-2025"
```

**After:**
```python
# config/settings.py using Pydantic Settings
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    metaculus_token: str
    submit_prediction: bool = True
    num_runs_per_question: int = 5
    tournament_id: str = "fall-aib-2025"

    class Config:
        env_file = ".env"

settings = Settings()
```

**Benefits:**
- ✅ Type-safe environment variable loading
- ✅ Validation at startup
- ✅ Easy to override for testing
- ✅ No hardcoded values in code

### 2. Separation of Concerns

Each module has a single, clear responsibility:

- **Config**: Settings and constants only
- **Models**: Data models with validation (Pydantic)
- **Clients**: External API interactions (Metaculus, LLM, Research)
- **Forecasting**: Core business logic for each question type
- **Utils**: Cross-cutting concerns (logging, formatting)

### 3. Better Error Handling

**Before:**
```python
try:
    response = requests.post(url, ...)
    if not response.ok:
        raise Exception(response.text)
except Exception as e:
    print(f"Error: {e}")
```

**After:**
```python
from bearbot.exceptions import MetaculusAPIError

try:
    response = requests.post(url, ...)
    if not response.ok:
        raise MetaculusAPIError(
            f"Failed to post: {response.status_code} {response.text}"
        )
except MetaculusAPIError as e:
    logger.error(f"Metaculus API error: {e}")
    # Specific error handling for API issues
```

**Custom Exception Hierarchy:**
```python
BearBotError (base)
├── MetaculusAPIError
├── ResearchError
├── LLMError
├── ParseError
└── ValidationError
```

### 4. Testability

**Before:**
```python
# Can't easily test without running the whole thing
# or mocking global variables
```

**After:**
```python
# tests/test_binary_forecaster.py
from unittest.mock import Mock, AsyncMock
import pytest

@pytest.mark.asyncio
async def test_binary_forecaster_extracts_probability():
    # Mock dependencies
    llm = Mock()
    llm.call = AsyncMock(return_value="After analysis... Probability: 75%")
    research = Mock()
    research.research = Mock(return_value="Test research")

    # Test
    forecaster = BinaryForecaster(llm, research)
    question = {
        "title": "Will X happen?",
        "description": "Background",
        "resolution_criteria": "Criteria",
        "fine_print": "Fine print",
    }

    prob, comment = await forecaster.forecast(question, num_runs=1)

    assert prob == 0.75
    assert "75%" in comment
    llm.call.assert_called_once()
```

**Benefits:**
- ✅ Each module can be tested in isolation
- ✅ Easy to mock dependencies
- ✅ Clear interfaces between components
- ✅ Fast unit tests without external API calls

### 5. Type Safety

**Before:**
```python
def get_binary_gpt_prediction(question_details: dict, num_runs: int):
    # question_details is an untyped dict
    title = question_details["title"]  # No autocomplete, no validation
```

**After:**

### 6. Structured Logging

**Before:**

**Benefits:**
- ✅ Log levels for filtering (DEBUG, INFO, WARNING, ERROR)
- ✅ Can write to files
- ✅ Structured format with timestamps
- ✅ Production-ready

## Migration Guide

### Quick Start Comparison

#### Running the Bot

**Old Way:**
```bash
python main_with_no_framework.py
```

**New Way:**
```bash
uv run python -m bearbot.main
# Or simply:
bearbot
```

#### Configuration

**Old Way:**
```python
# Edit constants at top of file
SUBMIT_PREDICTION = True
NUM_RUNS_PER_QUESTION = 5
TOURNAMENT_ID = "fall-aib-2025"
```

**New Way:**
```bash
# Create .env file
cat > .env << EOF
SUBMIT_PREDICTION=true
NUM_RUNS_PER_QUESTION=5
TOURNAMENT_ID=fall-aib-2025
EOF
```

#### Importing Components

**Old Way:**
```python
# Everything in one file
from main_with_no_framework import (
    get_binary_gpt_prediction,
    post_question_prediction,
    NumericDistribution,
)
```

**New Way:**
```python
# Clear imports from organized modules
from bearbot.forecasting import BinaryForecaster
from bearbot.clients import MetaculusClient
from bearbot.models import NumericDistribution
```

#### Creating a Forecaster

**Old Way:**
```python
# Direct function call, no dependency injection
forecast, comment = await get_binary_gpt_prediction(
    question_details,
    num_runs=5
)
```

**New Way:**
```python
# Dependency injection, testable
llm_client = LLMClient()
research = ResearchOrchestrator()
forecaster = BinaryForecaster(llm_client, research)

forecast, comment = await forecaster.forecast(
    question_details,
    num_runs=5
)
```

## Running the Code

### Setup

```bash
# Install dependencies (including new pydantic-settings)
uv sync

# Or with dev dependencies for testing
uv sync --dev
```

### Configure

Create a `.env` file in the project root:

```bash
# Required
METACULUS_TOKEN=your_token_here
OPENAI_API_KEY=your_key_here

# Optional research providers (at least one recommended)
ASKNEWS_CLIENT_ID=your_id
ASKNEWS_SECRET=your_secret
# OR
PERPLEXITY_API_KEY=your_key
# OR
EXA_API_KEY=your_key

# Bot configuration (optional, these are defaults)
SUBMIT_PREDICTION=false
USE_EXAMPLE_QUESTIONS=true
NUM_RUNS_PER_QUESTION=3
SKIP_PREVIOUSLY_FORECASTED_QUESTIONS=true

# LLM configuration (optional)
LLM_MODEL=gpt-4o
LLM_TEMPERATURE=0.3
CONCURRENT_REQUESTS_LIMIT=5

# Tournament selection (optional)

```

```bash

uv run python -m bearbot.main
```

## Appendix: Code Examples

### Example: Using the New API

```python
import asyncio
from bearbot.clients import MetaculusClient, LLMClient, ResearchOrchestrator
from bearbot.forecasting import ForecastOrchestrator
from bearbot.config import settings

async def main():
    # Initialize clients
    metaculus = MetaculusClient()
    llm = LLMClient()
    research = ResearchOrchestrator()

    # Create orchestrator
    orchestrator = ForecastOrchestrator(
        metaculus_client=metaculus,
        llm_client=llm,
        research_orchestrator=research,
    )

    # Get questions
    questions = metaculus.get_open_questions_from_tournament(
        settings.tournament_id
    )

    # Forecast
    await orchestrator.forecast_questions(
        open_question_id_post_id=questions,
        submit_prediction=settings.submit_prediction,
        num_runs_per_question=settings.num_runs_per_question,
        skip_previously_forecasted_questions=True,
    )

if __name__ == "__main__":
    asyncio.run(main())
```
